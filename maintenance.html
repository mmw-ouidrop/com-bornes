Préparer un message ou un média avant de l’afficher sur la borne

Cette page est ouverte depuis un fichier local (file://). Sous Firefox, le contenu validé peut ne pas être transmis à la page d’affichage. Utilisez l’adresse GitHub Pages ou un petit serveur local (voir README).

Média (facultatif)

Google Drive : ouvrez le dossier, faites un clic droit sur le fichier → Partager (« Toute personne disposant du lien ») → Copier le lien, puis collez-le ci-dessus. Pour une vidéo Drive, choisissez le type « Vidéo ». Un fichier importé depuis l’ordinateur reste sur cet ordinateur : il n’est envoyé sur aucun serveur.
